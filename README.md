# Portfolio | François Chamosset

Bienvenue sur le dépôt de mon portfolio personnel. Ce projet a été conçu avec un thème "Terminal" pour refléter mon environnement de développement, tout en garantissant des performances optimales grâce à l'utilisation de technologies natives.

## 🚀 Fonctionnalités Principales

- **Thème "Terminal"** : Interface sobre, orientée développement, avec effets néon vert et une typographie monospace (`Share Tech Mono`) évoquant un environnement console.
- **Système de Traduction (FR / EN)** : 
  - Bascule de langue fluide via un bouton de la barre de navigation.
  - Mémorisation de la préférence utilisateur via `localStorage`.
  - Gestion de la traduction via les attributs HTML (`data-i18n`).
- **Machine à Écrire (Typewriter Effect)** : Titre d'introduction interactif et dynamique.
- **Easter Egg Caché** : À vous de le trouver ! 😉

## 🛠️ Technologies Utilisées

Ce projet est construit sans aucun framework lourd afin d'assurer des temps de chargement ultra-rapides :

- **HTML5** (Structure sémantique)
- **CSS3 Vanilla** (Grid/Flexbox, Variables CSS, Animations, Media Queries)
- **JavaScript Vanilla** (Gestion du DOM, `localStorage`, balise `<canvas>`)
